# Metrics

Derived benchmark metrics live here.

Planned metrics include:

- generation wall time
- TTFT when available
- input / output / reasoning / cached token usage
- actual API cost
- estimated API-equivalent cost for subscription runs
- score per 1K output tokens
- score per dollar
- score per second
- output tokens per second
- generated lines and bytes

Quality score and efficiency metrics must remain separate so cheap or fast runs do not receive artificial quality bonuses.
