# LP Benchmark v1

Create a complete landing page for a fictional AI task-management product called **FlowPilot**.

## Product

FlowPilot uses AI to organize tasks, suggest priorities, and help users focus on the next action.

## Deliverables

Create exactly these files:

- `index.html`
- `style.css`
- `script.js`

Use only HTML, CSS, and Vanilla JavaScript. Do not use frameworks, UI libraries, external JavaScript libraries, external fonts, or image assets.

## Required sections

1. Header with FlowPilot logo, Features / How it works / Pricing navigation, CTA, and a mobile hamburger menu.
2. Hero with heading `Plan less. Get more done.`, supporting copy, primary and secondary CTAs, and a CSS-built dashboard mockup.
3. Features section with AI Prioritization, Smart Planning, and Focus Mode.
4. How it works section with three visually connected steps.
5. Final CTA with `Your next task is already waiting.` and `Start using FlowPilot` button.
6. Footer with `© 2026 FlowPilot` and Privacy / Terms / Contact links.

## Interaction requirements

- Working mobile hamburger menu.
- Smooth navigation scrolling.
- Simple visible feedback when a CTA is activated.

## Design requirements

Use a modern SaaS visual style with clear hierarchy, generous spacing, restrained gradients, card UI, subtle shadows, system fonts, and a consistent AI/productivity-oriented design.

The page must work naturally at:

- 1440px desktop
- 768px tablet
- 375px mobile

Do not allow horizontal scrolling.

## Accessibility

Use semantic HTML, correct button/link semantics, keyboard-accessible interactions, adequate contrast, and appropriate ARIA attributes where needed.

## Completion criteria

The result must work by opening `index.html` in a browser. Do not stop at an explanation; produce the complete working files.
